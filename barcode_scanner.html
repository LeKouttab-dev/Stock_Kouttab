Positionnez le code-barres dans le cadre vert

💡 Conseils pour une bonne détection :

  • Assurez-vous d'avoir une bonne luminosité
  • Tenez le code-barres bien droit et à plat
  • Évitez les reflets et les ombres
  • Placez le code entièrement dans le cadre vert
  • Maintenez une distance d'environ 15-20 cm
